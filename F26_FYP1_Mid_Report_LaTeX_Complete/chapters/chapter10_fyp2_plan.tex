\chapter{Remaining FYP Plan}

\section{Remaining Scope}
FYP-2 focuses on two priorities: (1)~optimizing the existing pipeline for speed, robustness, and edge-case handling, and (2)~building the semantic understanding layer and interactive web workspace that make the 3D model actionable for construction professionals. The complete model implementation (capture $\rightarrow$ upload $\rightarrow$ reconstruct) was delivered in FYP-1; FYP-2 makes it production-ready and feature-rich.

\section{Remaining Modules and Features}

\begin{enumerate}
    \item \textbf{Pipeline Optimization Module}: Reduce end-to-end processing time from 12--15\,min to $<$5\,min on RTX 4090. Techniques: faster COLMAP matching (vocabulary tree instead of exhaustive), reduced splatfacto iterations with early stopping, parallel step execution where possible, and optimized data transfer (compressed uploads, delta downloads).

    \item \textbf{Robustness Improvements}: Better handling of mirrors/glass (reflective surface detection and masking), textureless walls (depth-guided initialization), large rooms ($>$8\,m, tiled reconstruction), and variable lighting conditions.

    \item \textbf{Web Viewer Module}: Three.js / WebGPU-based Gaussian splat renderer with orbit/pan/zoom controls, running in any modern browser. Loads the \texttt{splat.ply} model exported by the pipeline.

    \item \textbf{Measurement Module}: Point-to-point distance tool in the metric 3D model. The user clicks two points on the splat surface; the system computes the Euclidean distance in metres using the Sim3-aligned coordinate frame. Target accuracy: $<$2\,cm for distances up to 10\,m.

    \item \textbf{Semantic AI Module}: YOLOv8-Seg instance segmentation trained on MEP components (pipes, conduits, HVAC ducts). 2D masks from multiple viewpoints are projected to 3D and merged via multi-view consensus to label regions of the point cloud.

    \item \textbf{Semantic Toggle UI}: System-level visibility controls in the web viewer---toggle pipes, conduits, and HVAC independently. Colour-coded overlays on the 3D model.

    \item \textbf{Dashboard Module}: Web-based project management dashboard showing scan history, processing status, model thumbnails, and measurement records.
\end{enumerate}

\section{Remaining Iterations}

\begin{itemize}
    \item \textbf{Iteration 2a (Weeks 1--4)}: Pipeline optimization and web viewer. Deliverable: processing time $<$5\,min on RTX 4090; browser-based splat viewer with point-to-point measurements validated on $\geq$3 rooms.

\section{Implementation Plan}

\paragraph{Iteration 2a: Optimization + Web Viewer (Weeks 1--4)}
\begin{enumerate}
    \item Profile pipeline bottlenecks; switch COLMAP to vocabulary-tree matching (week 1).
    \item Reduce splatfacto iterations with early-stopping on validation loss; benchmark on 3 scans (week 1--2).
    \item Set up React + Three.js project with Gaussian splat renderer and camera controls (week 2).
    \item Build measurement tool: ray-cast click $\rightarrow$ nearest splat $\rightarrow$ 3D coordinate $\rightarrow$ distance display (week 3).
    \item Validate measurement accuracy against tape-measure ground truth on 3 rooms (week 3--4).
    \item Integrate viewer with the FastAPI backend for model loading (week 4).
\end{enumerate}

\paragraph{Iteration 2b: Robustness + Semantic AI (Weeks 5--8)}
\begin{enumerate}
    \item Implement reflective surface detection and masking for mirrors/glass (week 5).
    \item Improve textureless-wall handling with depth-guided splat initialization (week 5--6).
    \item Collect and annotate MEP training data from captured scans (week 6).
    \item Train YOLOv8-Seg on MEP classes: pipe, conduit, HVAC duct (week 6--7).
    \item Implement 2D-to-3D mask projection and multi-view consensus (week 7--8).
    \item Add semantic toggle UI to the web viewer (week 8).
\end{enumerate}

\paragraph{Iteration 2c: Dashboard + Final Validation (Weeks 9--12)}
\begin{enumerate}
    \item Build web dashboard: scan list, processing status, model thumbnails (week 9--10).
    \item User testing with 5+ external users; collect usability feedback (week 10--11).
    \item Fix usability issues, write documentation (week 11--12).
    \item Final validation: measurement accuracy, semantic accuracy, processing time on 5+ rooms (week 12).
\end{enumerate}

\section{Testing and Validation Plan}
\begin{itemize}
    \item \textbf{Measurement accuracy}: Compare point-to-point measurements in the web viewer against tape-measure ground truth on $\geq$5 rooms of varying size and geometry. Target: $<$2\,cm error for distances up to 10\,m.
    \item \textbf{Semantic segmentation}: Evaluate YOLOv8-Seg on a held-out test set. Target: mAP$_{50} \geq 0.70$ for MEP classes.
    \item \textbf{3D projection accuracy}: Compare projected semantic labels against manually annotated 3D ground truth. Target: IoU $\geq 0.60$.
    \item \textbf{Web viewer performance}: Maintain $\geq$30\,FPS on a mid-range laptop (integrated GPU) for models up to 2\,million splats.
    \item \textbf{Usability testing}: Task completion rate $\geq$90\% for first-time users performing capture, viewing, and measurement tasks.
    \item \textbf{Processing time}: End-to-end pipeline $<$5\,min on RTX 4090 for a 5-minute scan. Benchmark each optimization individually.
    \item \textbf{Cross-browser}: Verify viewer on Chrome, Firefox, and Edge.
\end{itemize}

\section{Deployment Plan}
\begin{enumerate}
    \item \textbf{Server}: Deploy FastAPI backend + web viewer on a VPS with HTTPS (Let's Encrypt). Static assets served via CDN.
    \item \textbf{GPU processing}: Continue using RunPod on-demand pods. Evaluate RunPod serverless endpoints if job volume increases.
    \item \textbf{Android app}: Distribute APK via GitHub Releases. Google Play Store submission if time permits.
    \item \textbf{CI/CD}: Extend existing GitHub Actions to deploy web frontend on push to master.
\end{enumerate}
