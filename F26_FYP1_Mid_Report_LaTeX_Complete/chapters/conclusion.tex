\chapter{Conclusion}

This report presents the mid-evaluation status of BuildScan~3D, a system that converts casual smartphone video into metrically accurate 3D Gaussian Splatting models for indoor construction inspection.

\paragraph{Problem.} Existing 3D scanning solutions either require expensive hardware (Matterport, \$6{,}000+), lack metric scale (Luma AI, PocketGS), or demand expert operation (RealityCapture, manual COLMAP). No current system provides a fully automated phone-to-measurement pipeline with real-time capture guidance.

\paragraph{Research.} Our literature review and empirical experiments established four key findings: (1)~COLMAP SfM poses outperform ARCore poses for 3DGS training (training-view fit 21.9\,dB $\rightarrow$ $\sim$28\,dB and held-out SSIM 0.78 $\rightarrow$ 0.86 once ARCore's silent re-anchor and missing lens model were removed); (2)~dense MVS initialization is critical for splat geometry; (3)~aggressive regularization degrades quality when combined with Adam; (4)~gyro-aware frame selection outperforms texture-based sharpness metrics.

\paragraph{Design and implementation.} We built a three-tier system---Android capture app, FastAPI processing server, and cloud GPU pipeline---implementing all Iteration~1 features: ARCore capture with live IQA and coverage overlay, COLMAP SfM with Sim3 metric alignment, Nerfstudio splatfacto training, RunPod cloud GPU integration with guaranteed pod lifecycle management, and CI/CD via GitHub Actions.

\paragraph{Validation.} The current best model (v6) scores 26.52\,dB PSNR ($\geq$25\,dB target) and 0.8886 SSIM ($\geq$0.85 target) on 42 held-out frames. Tape-measure checks give a mean error of 4.8\,mm (0.19\%) on rigid objects and a worst case of 0.29\%, substantially better than the 5\% accuracy target. Processing currently takes about 75 minutes on an RTX 3070; the under-35-minute RTX 4090 target is projected and not yet measured.

\paragraph{Risks.} The primary risks are cloud GPU costs (mitigated by timeout watchdogs and guaranteed pod termination) and SfM failure on difficult scenes (mitigated by live IQA guidance). Mirrors and large untextured surfaces remain known limitations.

\paragraph{FYP-2 plan.} The remaining work focuses on making the 3D model actionable: a Three.js web viewer with point-to-point 1:1 measurement tools, completion of the structural layer (wall planes, corners, wall lengths, door detection) with automatic floor plans, and field validation on multiple rooms. The foundation built in FYP-1---metric accuracy, automated pipeline, and capture quality guidance---provides a solid base for these extensions.
