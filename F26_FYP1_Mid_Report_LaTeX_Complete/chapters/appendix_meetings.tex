\section{Progress Log}

    \item \textbf{ARCore capture app}: Basic recording $\rightarrow$ pose sync validation $\rightarrow$ IQA $\rightarrow$ coverage overlay $\rightarrow$ upload UI. Incremental feature additions documented with timestamps.

    \item \textbf{Reconstruction pipeline}: Initial ARCore-pose training (22.7\,dB PSNR) $\rightarrow$ COLMAP SfM integration (27.8\,dB) $\rightarrow$ Sim3 alignment (0.3\% scale) $\rightarrow$ gyro-aware frame selection (+0.26\,dB). Each improvement documented with before/after metrics.

\end{itemize}

\section{Problems and Solutions Summary}

Over 20 problems were encountered and resolved during development, documented in \texttt{docs/progress/Problems\_and\_Solutions.md}. The most significant:

\begin{enumerate}
    \item ARCore silent re-anchoring causing pose discontinuities (solved: anchor logging + IMU fallback)
    \item COLMAP lens distortion not matching ARCore intrinsics (solved: self-calibration)
    \item Degenerate splat geometry from custom training recipe (solved: adopted splatfacto)
    \item 30\,FPS input overwhelming COLMAP matching (solved: gyro-aware keyframe selection)
    \item RunPod SSH connection timing out (solved: polling with exponential backoff)
    \item GPU memory overflow on RTX 3070 (solved: cloud GPU support, image pinning)
\end{enumerate}
