# Section rewrites — paste your replacement text here

**How to use this file**

1. Find the section you want to rewrite in the index below.
2. Scroll to its block, and paste your new text between the `BEGIN` and `END` markers.
3. Write in **plain English prose, not LaTeX.** Don't worry about `\section{}`,
   `\textbf{}`, `\texttt{}`, escaping `%` or `_`, or table syntax. The cloud session
   converts it. If you want a list, just write dashes. If you want a table, write it as
   a plain Markdown table.
4. Leave any section you are *not* rewriting completely alone — blocks that still say
   `(not rewriting this one)` are skipped.
5. Set the intent line at the top of each block so the session knows what you want.
6. When you're done, commit this file, push, and run the cloud prompt at the bottom.

**Line numbers are from the current `shorten` branch and will drift as edits land.
Match on the section title, not the line number.**

## Rules that apply to every rewrite

The session applying these must obey all of the following. They are not negotiable.

1. **Never invent a measurement.** If your pasted text contains a number that is not
   already in the report, not in `docs/progress/`, and not in the Ground Truth table of
   `docs/report/REPORT_FIX_BRIEF.md`, the session must **flag it and leave the old number
   in place**, then list it in the log. It must not quietly accept a new figure.
2. **Never weaken an honesty marker.** "Not yet measured", "Not yet executed", "Not yet
   automated", "Partial" and "projection" must survive. If your pasted text upgrades one
   of these to a pass or a measured result, the session must flag it rather than apply it.
3. **Preserve every `\label{}`** in the replaced region, and keep `\ref`s resolving. If a
   label's table or figure is removed, repoint the references.
4. **Keep the section heading** unless you explicitly ask for a new title.
5. **Do not compile.** TeX Live is not installed in a cloud session.
6. **Do not touch** `scripts/`, `server/`, `src/` or `tests/`.
7. No AI-attribution trailers in commits (`AGENTS.md` section 4).
8. If a block below is empty or still says `(not rewriting this one)`, **skip it entirely.**
